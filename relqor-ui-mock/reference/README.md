# Reference

Bu klasör bilinçli olarak production source code içermez.

UI Developer'a ek referans ekran görüntüsü verilecekse:
- yalnız UI screenshot kullanın,
- device ID / gerçek konum / gerçek kullanıcı verisini temizleyin,
- backend URL / debug log görünmemeli,
- screenshot'ı tasarım kısıtı değil mevcut davranış referansı olarak işaretleyin.

Ana kaynak `docs/UI_STATE_CONTRACT.md` dosyasıdır.
